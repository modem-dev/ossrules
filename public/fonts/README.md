# JetBrains Mono

Unmodified regular and medium WOFF2 files from the [official JetBrains Mono repository](https://github.com/JetBrains/JetBrainsMono/tree/master/fonts/webfonts), downloaded September 14, 2026.

Distributed under the SIL Open Font License 1.1, included in `JetBrainsMono-OFL.txt`.

The application self-hosts these files through `next/font/local`. Body text uses Inter through `next/font/google`.

Social preview images use the unmodified regular TTF from
[JetBrains Mono v2.304](https://github.com/JetBrains/JetBrainsMono/blob/v2.304/fonts/ttf/JetBrainsMono-Regular.ttf),
under the same SIL Open Font License. The image renderer requires TTF, OTF, or WOFF rather than WOFF2.

## Inter

Social preview images also use the unmodified Inter regular TTF supplied by
[Google Fonts](https://fonts.gstatic.com/s/inter/v20/UcCO3FwrK3iLTeHuS_nVMrMxCp50SjIw2boKoduKmMEVuLyfMZg.ttf).
Its [SIL Open Font License](Inter-OFL.txt) is preserved alongside the font.
